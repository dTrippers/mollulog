# 개인정보처리방침

작성일: 2026년 8월 30일

개인정보처리자: Dimension Trippers

몰루로그는 서비스 운영에 필요한 정보만 처리합니다.

## 1. 수집하는 정보

로그인 또는 저장 기능을 이용하는 경우 아래 정보를 처리합니다.

| 구분 | 처리하는 정보 |
| --- | --- |
| 로그인 계정 (필수) | Google, GitHub, Discord에서 제공하는 계정 식별자 |
| Passkey | 자격 증명 ID와 공개키 등 인증 정보. 기기의 개인키나 생체정보는 몰루로그에 전달되거나 저장되지 않습니다. |
| 프로필 | 닉네임, 소개, 프로필 학생, 프로필 공개 설정 |
| 게임 기록 | 친구 코드, 회원 코드, 보유 학생, 모집 기록, 플래너·계산기 입력값, 작성한 게시물·의견 |
| 알림 | Discord 사용자 ID, 연결 상태, 알림 종류와 발송 시점 설정 |
| 스캐너 | 업로드한 스크린샷·영상, 파일명·형식·용량·해시, 인식 결과와 인식 과정에서 생성된 화면 이미지 |
| 문의 | 문의 제목·내용과 오류 제보에 이용자가 첨부한 정보 |

로그인 여부와 관계없이 서비스 운영에 필요한 시스템 이용 기록을 처리합니다.

| 구분 | 처리하는 정보 |
| --- | --- |
| 시스템 이용 기록 | 접속·기기·브라우저 정보, 쿠키 기반 설정값, 오류 및 방문 통계 정보 |

## 2. 이용 목적

수집한 정보는 로그인과 계정 유지, 개인 기록 저장, 문의 응답, 서비스 개선, 보안 및 오류 대응을 위해서만 사용합니다.

몰루로그는 위 목적을 벗어나 개인정보를 활용하지 않습니다.

## 3. 보관과 삭제

| 대상 | 보관과 삭제 |
| --- | --- |
| 계정과 프로필 | 이용자가 탈퇴할 때까지 보관합니다. 탈퇴하면 로그인 식별자, Passkey, 프로필 정보, 친구 코드, 연결 정보는 삭제하고 프로필은 비공개 처리합니다. |
| 작성 콘텐츠와 게임 기록 | 서비스 기록의 정합성을 위해 내부 식별자에 연결된 상태로 유지될 수 있으며, 다른 이용자에게 계정 정보가 표시되지 않도록 처리합니다. |
| 스크린샷 및 녹화 파일 | 작업 처리와 결과 확인에 필요한 기간 동안만 보관한 뒤 삭제합니다. |
| 쿠키 | 로그인 유지, 보안, 화면 설정 저장을 위해 사용합니다. 브라우저 설정에서 삭제하거나 차단할 수 있지만 일부 기능이 정상적으로 동작하지 않을 수 있습니다. |

## 4. 외부 서비스 이용

몰루로그는 서비스 제공을 위해 다음 외부 서비스를 사용합니다.

| 서비스 | 이용 목적 |
| --- | --- |
| Google, GitHub | 소셜 로그인 |
| Discord | 소셜 로그인, 알림 연결 및 발송 |
| Cloudflare | 웹 서비스, 세션·캐시, 업로드 파일 보관 및 보안 운영 |
| Amazon Web Services | 에셋 제공과 인프라 운영 |
| Google Analytics | 방문 통계 분석 |
| Sentry | 오류 분석 및 안정성 개선 |

## 5. 이용자의 권리

이용자는 자신의 개인정보를 열람·수정·삭제하거나 처리 정지를 요청할 수 있습니다. 계정 정보는 서비스 내 프로필 관리에서 수정하거나 탈퇴할 수 있으며, 그 밖의 요청은 [제안/문의 페이지](https://mollulog.net/contact)를 통해 문의해 주세요.

## 6. 변경 안내

이 방침이 변경되면 시행일과 변경 내용을 서비스 내에서 안내합니다.
